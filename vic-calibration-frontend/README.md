# VIC Calibration Interface

A frontend scaffold for a GIS-based interface to calibrate the VIC hydrological model through the existing RAT workflow. The initial workflow is RAT + VIC calibration.

## Requirements

- Node.js (with npm)

## Install dependencies

```bash
npm install
```

## Start the development server

```bash
npm run dev
```

Open the local URL printed by Vite in your browser.

## Build for production

```bash
npm run build
```

## Preview the production build

```bash
npm run preview
```

The current tabs are placeholders. The frontend uses mock-free placeholder content and has no backend, persistence, or scientific execution integration yet. UI reference images are kept in `prototype-1/`.
